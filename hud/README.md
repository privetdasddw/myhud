# hud — Cluster HUD

GTA V / FiveM композиция + premium automotive HUD: dark-glass элементы
вокруг круглого radar. Композиция — «орбита» из трёх спутников,
разнесённых по кругу примерно на 120°: плашка адреса **над** radar
(по центру), круглый бейдж микрофона на юго-западном радиусе круга,
справа — одна вертикальная колонка: полоса времени и погоды → кластер
автомобиля (скорость → передачи + лампа ремня → топливо) → радио-футер.

Ключевое правило вида: **фон есть только у самого элемента**. Больших
контейнеров, blur-панелей и «чёрных квадратов» нет ни одного.
Светлый текст несёт тонкую тёмную обводку (`--edge`), поэтому читается
на любом фоне игры.

## Масштаб

Размеры выведены из диаметра круга radar (`D`), а не из пикселей:

| элемент | доля D | 1080p |
|---|---|---|
| цифры скорости (cap) | ≈ 0.13 | ≈ 40px, кегль 2.6rem |
| буквы передач | ≈ 0.075 | ≈ 21px |
| время / температура | ≈ 0.068 | ≈ 24px |
| MPH, LIMIT, RDO | 0.03–0.05 | 15–18px |

Всё в `rem` от `html { font-size: clamp(11px, 100vh/54, 34px) }`, поэтому
на 1440p и 21:9 пропорции относительно radar не меняются.
HUD занимает ≈ 10% площади кадра и держится в левом нижнем углу.

## Установка

1. Папка `hud` уже лежит в `resources/`.
2. **Отключи старый HUD `location`** (иначе будут два интерфейса):
   убери/закомментируй `ensure location` в server.cfg.
3. Добавь: `ensure hud`.

Сам radar — ресурс `fh4map-1.4`, HUD его не трогает, а только
позиционируется вокруг (геометрия уже совпадает).

## Что отображается

| Блок | Данные |
|---|---|
| Плашка адреса (над radar) | пин · улица · postal · направление С/В/Ю/З — одна цельная группа, направление всегда замыкает блок |
| Бейдж микрофона (юго-западный радиус radar) | микрофон (выкл / вкл / говорит) |
| Полоса справа над кластером | время + часы/луна · погода + температура |
| Кластер автомобиля (справа) | `000` + MPH/KMH, знак лимита + «+N», селектор P R N D S, лампа ремня, топливо |
| Радио-футер (под панелью, во всю её ширину) | `RDO · CH-N` |

Кластер автомобиля показывается **только за рулём**: пешком скорость,
единицы, передачи, топливо и лимит полностью скрыты, чипы и адрес
остаются на месте.

Круиз-контроль в интерфейсе не отображается. Statebag `cruise` и поле
`cruise` в NUI-контракте сохранены для совместимости, UI их игнорирует.

## Шрифт

`Inter` (variable, latin + cyrillic subsets в `html/fonts/`) —
геометрический neo-grotesque с табличными цифрами: закрытые овальные
нули, ровная ширина цифр, чистые P/R/N/D/S. Один шрифт на весь HUD.
`Sofia Sans` оставлен фолбэком.

## Интеграции (все опциональные)

- **pma-voice** — состояние микрофона (Mumble) и радио (`radioChannel`).
- **gears** — `exports.gears:GetGearLabel()` для селектора (в т.ч. режим S).
- **postal** — база читается из `location/new-postals.json`
  (если положишь свой `new-postals.json` в корень `hud`, возьмётся он).
- **Температура** — событие `hud:setTemperature` (Celsius) или
  `location:updateTemp`; иначе оценка по погоде, кэшируется в KVP.
- **Лимит скорости** — `Config.SpeedLimit`, событие `hud:setSpeedLimit`
  или `exports.hud:setSpeedLimit(60)`. `0` — скрыть знак и «+N».

### Ремень

Лампа ремня живёт в правом конце строки передач — как индикаторы на
панели настоящего автомобиля. Источник задаётся `Config.SeatbeltSource`:
экспорт `ox_target`, player statebag или entity statebag
(`Config.SeatbeltStatebag`).

Если значения нет — лампа просто скрывается. Непристёгнутый ремень
подсвечивается акцентом. Statebag `cruise` продолжает читаться, но в
интерфейс не попадает.

## Экспорты

```lua
exports.hud:setSpeedLimit(60)
exports.hud:setTemperature(21.4)   -- Celsius
exports.hud:toggleHUD(true)        -- force show/hide
```

Команда `/hud` — ручное скрытие/показ.

## Производительность

- Единый цикл 400 мс (250 мс в машине), voice-цикл 100 мс.
- Diff-кэш: в CEF уходит только реально изменённое.
- Адрес пересчитывается после сдвига > 3 м.
- Без бесконечных CSS-анимаций: только переходы 150–350 мс по событию
  плюс одиночный `limitBump` при смене лимита.
- Compositing guard: кластер и ремень скрываются через `opacity`, а не
  `display`, и все поверхности заранее промоутятся `translateZ(0)` —
  CEF FiveM не создаёт новых слоёв в середине сессии и не теряет альфу.

## Превью в браузере

Открой `html/index.html` в Chrome — включится dev-режим с макетным
фоном и данными (`index.html?veh` — вариант в автомобиле). В FiveM
этот код не загружается.
